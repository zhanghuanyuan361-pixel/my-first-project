# 个人主页网站设计

## 背景

当前仓库只有一个 README，没有现成的页面、依赖或构建工具。本次工作为仓库创建一个可以直接在浏览器中打开的个人主页，先使用容易替换的示例内容。

## 目标

- 用原生 HTML、CSS 和 JavaScript 创建一个单页个人主页。
- 展示个人介绍、技能、项目和联系方式。
- 在桌面和手机屏幕上保持清晰、美观和可用。
- 提供适量的滚动、导航和按钮交互，让页面有现代感。
- 不引入框架、包管理器、外部图片或运行时服务。
- 让初学者可以通过三个文件理解页面结构、样式和行为。

## 页面结构

`index.html` 使用语义化区块组织页面：

1. 固定在顶部的导航栏，包含品牌标识、桌面导航和移动端菜单按钮。
2. Hero 首屏，展示示例姓名、身份、简介和两个行动按钮。
3. 关于区块，展示简介和地点、工作方式等简要信息。
4. 技能区块，用卡片展示 HTML、CSS、JavaScript、UI 设计和响应式开发。
5. 项目区块，用三张卡片展示示例项目、类型、简介、技术标签和链接。
6. 联系区块，展示邮箱、GitHub、所在地以及联系按钮。
7. 页脚和返回顶部按钮。

示例内容使用清晰的中文文案，并在 HTML 中保持集中、易于搜索替换。项目链接使用安全的占位链接，不声称存在真实项目。

## 视觉与响应式设计

`style.css` 使用 CSS 自定义属性集中管理颜色、间距、圆角和阴影。整体采用深色蓝紫背景、青绿色强调色、渐变光晕和半透明卡片；不依赖外部字体或图片资源。

- 桌面端使用宽度受限的内容容器和双列/三列网格。
- 低于移动断点时改为单列布局，导航收起为菜单按钮。
- 卡片、按钮和链接有清楚的悬停、焦点和按下状态。
- `prefers-reduced-motion: reduce` 时关闭位移和淡入动画。
- 颜色对比度、键盘焦点和语义标签满足基本可访问性要求。

## 交互行为

`script.js` 只负责页面行为，不承担内容渲染：

- 切换移动端导航菜单，并在选择导航链接后关闭菜单。
- 使用 `IntersectionObserver` 为内容区块添加一次性的进入视口动画。
- 根据滚动位置给当前导航链接添加活动状态。
- 页面向下滚动后显示返回顶部按钮，点击后平滑回到顶部。
- 点击复制邮箱按钮时使用 Clipboard API；成功或失败都显示短暂的可见提示。
- 对缺少 Clipboard API 的浏览器提供可继续使用的邮箱链接作为后备。

## 文件职责

- `index.html`：页面内容、语义结构、导航锚点和可访问性属性。
- `style.css`：颜色、布局、响应式规则、动画和状态样式。
- `script.js`：菜单、滚动观察、活动导航、返回顶部和复制反馈。

## 验证策略

完成实现后执行以下检查：

- 检查 Git 差异，确认只新增预期文件并保留原有文件。
- 用静态检查确认 HTML 包含所有主要区块且正确引用 CSS/JavaScript。
- 使用 Node 的语法检查验证 `script.js`。
- 启动 Python 本地静态服务器，用 HTTP 请求确认 `index.html`、`style.css` 和 `script.js` 都能返回。
- 在浏览器不可用的情况下，使用源码检查覆盖响应式断点、减少动画规则和关键交互监听器。

## 不在本次范围内

- 不添加框架、构建工具、后端、表单提交服务或数据库。
- 不部署网站，不修改远端仓库，不合并到主分支。
- 不创建真实社交资料、真实项目地址或用户凭据。
