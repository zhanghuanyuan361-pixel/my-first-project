# 前端学习路线

这份路线按“理解一个概念、修改一处代码、马上看到结果”的节奏进行。

## 第一阶段：HTML

- 认识页面骨架
- 学习标题、段落、链接和按钮
- 理解 `class`、`id` 和语义化区块
- 练习增加项目卡片

## 第二阶段：CSS

- 修改颜色和字体
- 理解 margin、padding 和盒模型
- 使用 Flex 和 Grid
- 学习媒体查询和手机端布局

## 第三阶段：JavaScript

- 用 `querySelector` 找到元素
- 用事件监听器响应点击
- 用 `classList` 切换样式
- 用函数整理重复动作

## 第四阶段：项目实践

- 替换成自己的资料
- 增加一个真实的小项目
- 修复手机端显示问题
- 用测试和 Git 提交保存每一步
