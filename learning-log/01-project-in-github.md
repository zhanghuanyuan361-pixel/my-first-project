# 第 1 次学习：把个人主页放进 GitHub

日期：2026-10-23

## 今天完成了什么

我确认了自己的 GitHub 仓库，并创建了 `learning/first-homepage` 学习分支。

这次把个人主页项目按职责放进了仓库：

- `index.html)：网页内容和结构
- `style.css`：颜色、布局和响应式样式
- `script.js`：网页交互
- `tests/portfolio-smoke.mjs`：基础检查
- `README.md`：学习路线和项目说明

## 我学到的概念

一次 Git 提交可以看成项目在某个时刻的快照。

这次提交历史按照学习顺序分成了几步：

1. 添加 HTML 页面结构
2. 添加 CSS 视觉系统
3. 添加 JavaScript 交互
4. 添加测试
5. 添加学习说明

这样以后查看 GitHub 的提交记录时，可以看见项目是怎样一步一步长出来的。
